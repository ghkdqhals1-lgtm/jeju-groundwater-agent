# AI 활용 범위 명시

제주 삼다수 취수원 지하수 Agent | 작성자: 황보민

## 1. 개요
- 분석 계산(센서 이상 진단, 상태 등급, 2주 예측)은 LLM이 아니라 규칙·통계 코드가 수행하며, 런타임의 LLM은 예측하지 않습니다. LLM은 질문에 맞는 도구를 고르고 도구 결과를 쉬운 말로 설명합니다.
- 주제, 사용자, 핵심 기능, 설계 결정, 결과 검토와 승인은 본인(황보민)이 했고, 코드 구현과 문서 초안은 AI(Claude Code)가 작성했습니다.

## 2. 본인(황보민)이 한 것
- 후보 데이터 검토와 주제 선정: 지하수 감시정 142·79번과 기상 756·757번. 처음 검토한 전기차 BMS 데이터는 접근 승인이 나지 않아 제외
- 제주데이터허브 프로젝트 생성과 API 키 발급, Claude API 키 발급과 `.env` 관리
- 주 사용자(물 관리 담당자 우선, 도민 보조)와 핵심 기능 3개(센서 이상 진단, 상태 진단, 2주 예측) 결정
- 데이터를 확인한 뒤의 설계 결정: 현재 기준 시점 2023-06-30, 1수원 감시정1·2의 비교 기준, 수온의 보조 지표·값 고착 탐지 역할, 마지막 3개월 검증
- 1수원 감시정1·2의 추세 이탈 기준을 결과에 맞춰 바꾸지 않고 그대로 두기로 한 결정
- 측정값 방향을 '물까지의 깊이'로 해석하고 한 줄로 전환할 수 있게 설계하기로 한 결정, 데이콘 게시판 문의
- LLM으로 Claude API(claude-sonnet-5-5) 선택
- 화면 실행·확인과 개선 지시(비용·토큰 숨김, 도민 모드 단순화)
- 실행 결과 검토, 지시와 승인

## 3. AI가 한 것

| 도구 | 한 일 |
|---|---|
| Claude (채팅) | 후보 데이터셋 조사·비교, 설계안과 작업 지시문 작성, 결과 해석 보조, 참고 자료 검색(개발공사 연구, 기사) |
| Claude Code | 코드 구현 전부(전처리, 기상 수집, 센서 이상 진단, 상태 진단, 2주 예측, Agent, Streamlit 화면), 시험 실행, 계획서와 문서 초안 작성 |
| Claude API (claude-sonnet-5-5) | 서비스 실행 중 질문마다 도구를 고르고 결과를 설명 |

## 4. 사용한 AI 모델
- 서비스 런타임: claude-sonnet-5-5 (`.env`의 `ANTHROPIC_MODEL`로 변경 가능, 비우면 이 모델)
- Claude Code: claude-opus-5-5(코드 구현), claude-sonnet-5-5(문서 작업)
- Claude 채팅: Claude Opus 5.5(데이터 조사, 설계안·작업 지시문 작성, 결과 해석 보조)

## 5. 외부 API·서비스
- Claude API(Anthropic): Agent의 LLM. 키는 `.env`에만 두며, 질문 하나에 약 0.01~0.1달러의 비용이 듦
- 제주데이터허브 API(756번 일별 기상, 757번 기상관측소): 기상 데이터 수집에 사용. 수위·수온은 허브에서 받은 CSV(142·79번)

## 6. 외부 데이터
- 제주데이터허브 142·79·756·757번
- 참고 문헌: 제주도 지하수 관리수위 설정에 관한 연구(2005), 신문주 외(2020), 가뭄 제한급수 기사(2026). 링크는 `docs/DATA_SPEC.md`에 수록
- 이용조건: 허브에 별도 이용조건 표시가 없어 출처를 표기하고 대회 목적으로만 사용. 제출 ZIP의 데이터는 대회 심사 목적으로만 포함하며 외부 공개·재배포를 금지

## 7. 오픈소스·외부 코드
- 라이브러리: anthropic 2.8.0, matplotlib 3.11.2, numpy 2.5.4, pandas 3.1.1, python-dotenv 1.2.4, requests 2.34.2, streamlit 1.66.1. 라이선스는 `docs/DATA_SPEC.md` 6장에 수록
- 예측 모델(릿지 회귀)은 numpy로 직접 구현. 외부 저장소의 코드는 사용하지 않음

## 8. 검증
AI가 작성한 코드와 문서는 본인이 실행 결과를 검토하고 승인했습니다.
