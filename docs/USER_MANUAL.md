# 사용자 매뉴얼

지하수 감시정 Agent를 처음 쓰는 분을 위한 안내입니다. 프로그램을 잘 몰라도 따라 할 수 있게 썼습니다.

## 1. 화면 실행하기
1. 담당자가 준비해 둔 폴더의 터미널(PowerShell)을 엽니다.
2. 다음 한 줄을 입력하고 Enter를 누릅니다.
   `.venv\Scripts\streamlit run src/app.py`
3. 처음 한 번 "Email"을 물으면 아무것도 쓰지 말고 Enter를 누릅니다.
4. 브라우저가 열리고 화면이 나옵니다. 하얀 화면이면 잠시 뒤 새로고침하세요.
5. 끝낼 때는 터미널에서 Ctrl+C를 누릅니다.

화면이 열려도 키가 없으면 빨간 안내가 나옵니다. 이때는 담당자에게 `.env` 설정을 부탁하세요(README 참고).

## 2. 화면 구성
- 맨 위 노란 안내: 데이터가 2022-01-01 ~ 2023-06-30까지이며 '지금'은 2023-06-30 기준이라는 설명입니다.
- 가운데: 질문과 답변이 채팅처럼 쌓입니다. 아래 입력창에 질문을 씁니다.
- 왼쪽 사이드바: 사용자 모드(담당자/도민), 예시 질문 버튼 6개, 대화 지우기, 이번 세션 질문 수, 개발자 정보 보기 체크박스.
- 맨 아래: 분석은 규칙과 통계 모델이 하고 AI는 도구를 골라 설명한다는 안내입니다.

## 3. 질문하는 방법
예시 질문(버튼을 누르면 바로 물어봅니다)
- 2수원 감시정1 지금 상태 어때?
- 요즘 지하수 괜찮아?
- 이상한 감시정 있으면 알려줘.
- 1수원 감시정3 값 믿어도 돼?
- 비가 안 오면 2주 뒤에 어떻게 돼?
- 2022년 9월에 1수원 감시정3에서 무슨 일이 있었어?

요령
- 감시정 이름은 "1수원 감시정3"처럼 쓰면 됩니다(1수원 감시정1~3, 2수원 감시정1~3 모두 6곳).
- 기간을 물을 때는 2022년 1월 ~ 2023년 6월 안의 날짜로 물어보세요.
- 그래프가 필요하면 "1수원 감시정3 2022년 9월 수위 그래프 보여줘"처럼 부탁하세요.
- 이어서 물어봐도 됩니다. 최근 4번의 질문과 답변을 기억합니다.

## 4. 답변 읽는 법
- 등급(정상/주의/경고): 이 감시정의 18개월 기록 안에서 지금 물이 어느 정도인지 나타냅니다. 법이나 제도의 공식 기준이 아닙니다.
- 물 높이 백분위(낮은 쪽부터): 82%라면 지금 물 높이가 18개월 중 낮은 쪽에서 82% 위치라는 뜻입니다. 숫자가 클수록 물이 높은 편입니다.
- 측정값: 이 프로젝트는 측정값을 '물까지의 깊이'로 해석했습니다. 값이 클수록 지하수가 낮다는 뜻입니다.
- 예상 범위: 앞으로 값이 들어올 것으로 보는 대략의 구간입니다.
- 시험 포함률: 그 예상 범위가 과거 시험에서 실제 값을 얼마나 담았는지입니다. 목표는 80%인데 실제로는 이보다 낮은 경우가 많았습니다. 낮을수록 범위를 믿기 어렵다는 뜻입니다.
- 신뢰도 표시: "참고 가능"은 참고할 수 있다는 뜻이고, "큰 변화 구간에서 오차가 큼"이 붙으면 예측이 많이 틀릴 수 있다는 뜻입니다.
- 추세와 예측이 어긋남: 최근 변화 방향과 예측이 맞지 않는다는 표시로, 그 감시정의 예측은 참고하기 어렵다는 뜻입니다.
- 센서 이상 '의심': 센서 문제일 수도 있다는 뜻이지 고장이라고 확정한 것이 아닙니다. 큰 비 뒤의 변화일 수도 있어서 현장 점검으로 확인해야 합니다.
- 답변 끝의 근거와 한계 두 줄을 꼭 함께 읽으세요.

## 5. 담당자 모드와 도민 모드
- 담당자: 수치와 근거를 자세히 보여주고, 표도 사용합니다.
- 도민: 표 없이 10줄 안쪽으로 쉬운 말로 알려주고, 어려운 숫자는 말로 풀어 줍니다.

## 6. 개발자 정보 보기
사이드바 맨 아래 체크박스이며 처음에는 꺼져 있습니다. 켜면 답변 아래에 '비용·시간·토큰'이 나오고 사이드바에 '추정 비용 합계'가 나옵니다. '사용한 도구'는 담당자 모드에서는 항상 보이고, 도민 모드에서는 이 체크박스를 켰을 때만 보입니다. 일반 사용에는 필요하지 않습니다.

## 7. 할 수 없는 질문
- 수질·오염·먹는 물 안전성: 이 데이터(수위·수온·강수)에는 없습니다. 공식 수질 검사 결과를 확인하세요.
- 2023-06-30 이후 또는 2022-01-01 이전(예: 2024년 1월 수위): 조회할 수 없습니다.
- 취수량, 공식 제한 단계 판정, 2주보다 먼 예측도 하지 않습니다.

## 8. 문제가 생겼을 때
| 증상 | 해결 |
|---|---|
| "키 없음" 안내 | `.env`에 Claude 키가 있는지 담당자에게 확인 |
| "인증 실패" | 키가 맞는지 확인 |
| "잔액 부족" | Claude Console에서 결제(크레딧)를 확인 |
| "네트워크 오류" | 인터넷 연결 확인 후 다시 질문 |
| "예측 모델 파일이 없습니다" | 화면 위의 '예측 모델 만들기(약 2분)' 버튼 누르기 |
| 하얀 화면 | 잠시 뒤 새로고침 |
| 답이 이상해 보임 | 개발자 정보 보기를 켜서 사용한 도구를 확인하고 담당자에게 알리기. 답변 문장은 질문할 때마다 조금씩 달라질 수 있습니다 |
